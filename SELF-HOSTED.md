# Self-hosted instance

This repo is a private copy of [anuraghazra/github-readme-stats](https://github.com/anuraghazra/github-readme-stats),
deployed to Vercel to back the stat cards on my GitHub profile README
(https://github.com/ramnivasattanti2008-cloud/ramnivasattanti2008-cloud), so they aren't
subject to the shared public instance's rate limit.

The `PAT_1` environment variable (a GitHub classic token, `repo` scope) is set directly
in the Vercel project's dashboard and is never committed here.
